# BMA-Trainer

Interaktive Feuerwehr-Übung mit drei fiktiven Lagen. Du liest das
Feuerwehr-Anzeigetableau (FAT), wählst eine Laufkarte, erkundest den
Melderbereich und bedienst das Feuerwehr-Bedienfeld (FBF).
Die Bedienfelder und die Rückstellung sind vereinfacht simuliert.

## Lokal starten

Öffne `index.html` im Browser. Alle Bestandteile der Simulation sind in
dieser Datei enthalten.

## Auf GitHub Pages veröffentlichen

1. Erstelle auf GitHub ein Repository, zum Beispiel `bma-trainer`.
2. Entpacke das ZIP und lade die Dateien direkt ins Hauptverzeichnis des
   Repositorys auf den Branch `main`. Lege auch die leere Datei `.nojekyll`
   dort ab. Falls sie im Dateimanager ausgeblendet ist, blende versteckte
   Dateien ein oder lege sie direkt im Repository an.
3. Öffne **Settings → Pages** und wähle bei **Source** die Einstellung
   **Deploy from a branch**.
4. Wähle **main** und **/(root)** und klicke auf **Save**.
5. Nach dem Deployment steht die Adresse unter **Settings → Pages**.

[GitHub-Dokumentation zu Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
